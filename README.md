# Афиша культуры Башкортостана — Уровень 1 («Бот»)

Информационный сервис культурных мероприятий Республики Башкортостан (концерты, спектакли, выставки, фестивали, кинопоказы, экскурсии).

> **Дисклеймер:** Решение разворачивается в отдельном демонстрационном контуре и не является официальным сервисом Министерства культуры Республики Башкортостан до его штатного подключения. В действующие системы министерства изменения не вносятся.

## Выбранный уровень решения

Зафиксированный уровень выполнения в соответствии с разделом 5 ТЗ: **Уровень 1 — «Бот» (база: 30 баллов)**.

Состав реализованного функционала Уровня 1 (разделы 6.1, 6.2, 8, 9.1, 10 ТЗ):
- **Каталог событий в реляционной БД** (полная схема раздела 8.1 + справочники городов, площадок и категорий раздела 8.2).
- **Раздельное хранение сырых и нормализованных данных**: исходные записи сохраняются в таблице `raw_events`, что позволяет переиграть нормализацию (`reprocess-raw`) без повторного сбора.
- **Идемпотентный импорт CSV/JSON и ручной ввод**: валидация обязательных полей, пометка спорных карточек (`is_disputed`, `dispute_reason`), дедупликация по `source_hash` и `dedup_key`, детальный отчёт об импорте (добавлено, обновлено, без изменений, отклонено и почему).
- **Поддержка всех статусов событий**: `опубликовано`, `черновик`, `отменено`. Отменённые события исключены из поисковой выдачи, но остаются доступными по прямой команде/ссылке (`/event_<id>` или `/start event_<id>`) с явной пометкой об отмене.
- **Журнал изменений (`audit_log`)**: фиксация каждого действия (кто, когда и какие поля изменил).
- **Telegram-бот на русском языке**:
  - `/start` — приветствие и компактное главное меню на инлайн-кнопках;
  - поиск и фильтрация по названию, городу/населённому пункту (с исправлением опечаток по Дамерау — Левенштейну, например *«стерлитакмае» → «Стерлитамак»*), категории, дате (`сегодня`, `завтра`, `выходные`, `неделя`, `до конца месяца`, конкретная дата `ДД.ММ.ГГГГ`), цене (`бесплатно`, `до 500 ₽`, `до 1000 ₽`, `до 1500 ₽`, расчёт бюджета «на двоих/троих»), длительности и возрасту (`0+`, `6+`, `12+`, `16+`, `18+`);
  - путь до полной карточки события — **не более 3 действий**;
  - объяснение пустого результата с проверкой того, какое именно ограничение мешает и сколько событий найдётся при его ослаблении;
  - пагинация (кнопка «Показать ещё») и обработка свободного текста как поискового запроса без возврата в меню;
  - подписка на город и категорию и мгновенная отписка одной командой (`/unsubscribe`).

## Быстрый запуск (`docker compose up`)

Время развёртывания с нуля до рабочего состояния — **менее 2 минут** (по ТЗ не более 10 минут).

1. Скопируйте файл переменных окружения и при наличии укажите токен бота от `@BotFather`:
   ```bash
   cp .env.example .env
   ```
2. Запустите сервис одной командой:
   ```bash
   docker compose up --build
   ```
При старте контейнер автоматически дождётся готовности PostgreSQL, идемпотентно применит SQL-миграции (`migrations/001_initial_schema.sql`), заполнит справочники городов, площадок и категорий (`data/dictionaries.json`), загрузит подготовленный набор событий (`data/seed_events.json`) и запустит Telegram-бота. Повторный перезапуск контейнера не ломает схему и не создаёт дублей.

## Локальный запуск и работа через CLI (без Docker)

Для быстрой локальной проверки и демонстрации без контейнера PostgreSQL поддерживается встроенный адаптер SQLite:

```bash
# 1. Прогон всех автоматических тестов
PYTHONPATH=. python3 -m unittest discover -s tests -v

# 2. Проверка выполнения всех 6 метрик качества Раздела 9.1 ТЗ
PYTHONPATH=. python3 -m src.cli metrics

# 3. Поиск событий из командной строки
PYTHONPATH=. python3 -m src.cli search "Куда пойти в субботу с ребёнком 8 лет в Стерлитамаке, до 1000 рублей на двоих, чтобы закончилось не позже 20:00"

# 4. Импорт файла CSV или JSON с выводом отчёта
PYTHONPATH=. python3 -m src.cli import data/import_100_events.csv --actor moderator_1

# 5. Ручной ввод нового мероприятия
PYTHONPATH=. python3 -m src.cli add-manual \
  --title "Вечер башкирского романса" \
  --category "концерт" \
  --date-start "2026-11-21T19:00:00" \
  --city "Уфа" \
  --venue "ГКЗ «Башкортостан»" \
  --address "ул. Ленина, 50" \
  --description "Концерт ведущих солистов филармонии." \
  --source-url "https://gkzbashkortostan.ru/afisha/romans" \
  --price-min 400 --price-max 900 --age-limit 6

# 6. Просмотр очереди спорных карточек и смена статуса события (модерация)
PYTHONPATH=. python3 -m src.cli list-disputed
PYTHONPATH=. python3 -m src.cli set-status 11111111-1111-4111-8111-000000000020 опубликовано --actor moderator_1

# 7. Переигрывание нормализации по сырым данным без повторного сбора
PYTHONPATH=. python3 -m src.cli reprocess-raw

# 8. Просмотр журнала изменений (кто, когда и что изменил)
PYTHONPATH=. python3 -m src.cli audit-log --limit 15
```

## Модель и стоимость диалога (Раздел 10, 11, 12 ТЗ)

- На **Уровне 1 («Бот»)** используется детерминированный алгоритмический разбор поисковых запросов (`src/services/normalizer.py`) с морфологической нормализацией, словарём синонимов категорий и нечётким сопоставлением городов по расстоянию Дамерау — Левенштейна без обращения к платным внешним LLM API.
- **Стоимость одного диалога**: **0,00 ₽** (внешние платные токены не расходуются, работоспособность 100 % автономна и не зависит от доступности внешних ИИ-провайдеров).

## Обработка персональных данных и срок хранения подписок (Раздел 10 ТЗ)

- В таблице `subscriptions` хранятся исключительно технический идентификатор пользователя Telegram (`user_id`), выбранный город (`city`), категория (`category`), дата создания и дата истечения подписки (`expires_at`).
- Телефоны, домашние адреса, ФИО и имена пользователей **не запрашиваются и не сохраняются**.
- В структурных JSON-логах (`src/utils/logger.py`) идентификатор пользователя односторонне хешируется (`SHA-256` с префиксом `usr_`), а любые случайные телефоны или email-адреса в тексте автоматически маскируются (`[REDACTED_PHONE]`, `[REDACTED_EMAIL]`). Каждому запросу присваивается сквозной `request_id`.
- **Срок хранения подписок**: по умолчанию **180 суток** (`SUBSCRIPTION_RETENTION_DAYS=180`), после чего запись автоматически очищается методом `cleanup_expired()`. При вызове команды `/unsubscribe` или нажатии кнопки «Отписаться» запись **немедленно и физически удаляется** из БД (`DELETE FROM subscriptions`).

## Известные ограничения Уровня 1

1. В соответствии с выбранным **Уровнем 1 («Бот»)** веб-каталог, публичный REST API с OpenAPI, виджет для встраивания (Уровень 2), LLM-агент с многошаговой памятью (Уровень 3) и автоматический краулер внешних сайтов (Уровень 4) не входят в объём работ данного контура.
2. Оценка времени в пути между точками города («ехать не больше 20 минут») без подключения внешнего геосервиса в Уровне 1 не рассчитывается; фильтрация выполняется по городу, площадке, дате, времени начала/окончания, длительности, стоимости и возрасту.
