# Культура Башкортостана — frontend

Next.js App Router · TypeScript · Tailwind CSS. Самостоятельное приложение; Python backend, миграции и бот не изменяются.

## Запуск

```sh
cd frontend
cp .env.example .env.local
npm ci
npm run dev
```

Откройте http://localhost:3000. В отдельном терминале из корня проекта запустите FastAPI с локальной SQLite:

```sh
DATABASE_URL=sqlite:///data/afisha_local.db .venv/bin/uvicorn src.api:create_app --factory --host 127.0.0.1 --port 8000
```

Явное `DATABASE_URL=...` важно: в корневом `.env` адрес `db` предназначен для контейнеров Compose и не разрешается на Mac при локальном запуске Uvicorn. Локальный API сам применит миграции и загрузит сиды в `data/afisha_local.db`.

Если нужна локальная разработка с PostgreSQL, сначала поднимите БД командой `docker compose up -d db`, затем запустите API с `DATABASE_URL=postgresql://afisha_user:afisha_dev_password@127.0.0.1:5433/afisha_db` (или подставьте ваши значения Compose). Compose публикует PostgreSQL на хосте через порт 5433, чтобы не конфликтовать с локальным PostgreSQL на 5432. Для полного стенда используйте из корня `docker compose up --build`.

`API_BASE_URL` — origin FastAPI без `/api/v1` (по умолчанию `http://127.0.0.1:8000`). После изменения env перезапустите Next.js. При сборке для другого окружения задайте URL до `npm run build`: rewrite фиксируется сборкой. Серверные страницы обращаются напрямую; браузерная форма использует same-origin proxy `/backend/*`, поэтому дополнительных CORS-настроек не требуется. Секреты в frontend env добавлять не нужно.

## Каталог

- `/` — hero с кураем, поиск, города и категории из API, три ближайших события (дата республики, UTC+5).
- `/events` — поиск по тексту, городу, категории, площадке, периоду, максимальной цене, бесплатному входу и возрастной маркировке. Сортировка: ближайшие, поздние, дешёвые.
- Форма отправляется кнопкой или Enter; изменение условий сбрасывает страницу. Query-параметры сохраняют выдачу при перезагрузке, переходах назад/вперёд и передаче ссылки. Скрытые дополнительные фильтры API из URL сохраняются до полного сброса.
- Пагинация использует `page`, `page_size`, `total`, `pages` API. Размер страницы по умолчанию — 12. Есть переход к первой странице при устаревшем номере.
- `/events/[id]` — постоянная страница события, включая статус, 404 и обработку недоступности API.
- `/feedback` — существующая форма обратной связи.

События и справочники поступают только из `src/lib/api.ts`. Фильтрация, подсчёт и сортировка выполняются FastAPI. Орнамент карточек декоративный. Никаких фиктивных событий во frontend нет.

Независимые Suspense-границы показывают загрузку справочников и событий. При ошибках API повторная загрузка сохраняет URL; при 422 отображается подсказка; при пустой выдаче — объяснение backend и сброс условий. Недоступность одного справочника не скрывает результаты. Даты без timezone интерпретируются как UTC+5.

## Проверки

```sh
npm run lint
npm run typecheck
npm test
npm run smoke:embed # после npm run start
npm run build
npm start
```

`smoke:embed` проверяет HTTP-ответ `/embed`, параметры города/категории/периода и iframe шириной 360 px. Визуальную проверку выполняйте в браузере на отдельной HTML-странице.

Компактные тесты URL в `tests/event-query.test.mjs` запускаются на Node 22.18+ или 24. Проверяются все поля, кириллица, нулевые ограничения, пагинация и некорректные query-параметры. Новые зависимости не нужны.

Если sandbox запрещает локальные порты внутренних процессов Turbopack, используйте `npm run build -- --webpack`.

Для браузерной проверки запустите FastAPI отдельно. Сопоставьте карточки с `/api/v1/events` при одинаковом `page_size`, проверьте каждый фильтр, сочетание фильтров, сортировку, следующую/предыдущую страницу, сброс страницы после отправки формы, перезагрузку и Back/Forward. Проверьте пустую выдачу, ошибочный период, устаревшую страницу и отключение/повторное включение API. На ширинах 360/768/1440 px проверьте отсутствие переполнения, Tab/Shift+Tab, Enter в поиске, skip-link и мобильное меню.

## Результат проверки каталога

ESLint, TypeScript, три URL-теста и production build с `--webpack` прошли. Стандартный Turbopack build ограничен запретом sandbox на внутренний локальный порт.

В Chrome проверены реальные ответы FastAPI с существующим `data/seed_events.json` в отдельной базе в памяти: все фильтры, их сочетание, нулевая цена и возраст, сортировка, страницы, сброс, reload, Back/Forward, постоянный ID, пустая выдача и 422. На главной, в каталоге и деталях при 360/768/1440 px нет горизонтального переполнения; axe WCAG A/AA не выявил нарушений. Проверены skip-link и отправка поиска клавиатурой. При фактически выключенном API проверены ошибки трёх страниц, сохранение фильтров и повторная загрузка без изменения URL. Ошибок JavaScript в браузере нет. Рабочая база не использовалась.
