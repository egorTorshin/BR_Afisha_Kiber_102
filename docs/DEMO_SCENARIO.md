# Демонстрация Уровня 3 — ровно 5 минут

Перед показом: `docker compose up -d --build --wait`, убедиться, что `/health` отвечает. Использовать только подготовленный каталог; запись экрана для резерва готовится отдельно. Сервис демонстрационный и не является официальным сайтом министерства.

| Время | Действие | Что показать |
|---|---|---|
| 0:00–1:00 | Открыть Telegram `/start`; нажать «🔎 События», затем карточку. | Компактное меню, источник, цена, статус и ссылка в карточке; два нажатия до карточки. |
| 1:00–2:00 | В свободном тексте запросить «Концерт в Уфе на выходных до 1500 рублей», затем «подешевле», «только бесплатные», «в другой день», уточнить «15.11.2026» и «а ещё». | Фильтры изменяются относительно диалога. Показать «🔄 Сбросить фильтры» и сверить, что сброс очищает контекст. |
| 2:00–3:00 | Спросить «Отменили ли спектакль 14 ноября?»; после уточнения назвать «Ревизор». | При нескольких спектаклях агент уточняет название, затем проверяет отменённую запись и источник, не выдаёт другие события вместо статуса. |
| 3:00–4:00 | Запросить подписку на концерты в Уфе, ответить «да» и повторить «да»; открыть веб-чат и API `/docs`. | До подтверждения записи нет, повтор не создаёт вторую. Бот и сайт используют общий агентный сервис; контракт API доступен. |
| 4:00–5:00 | Показать трассу запроса и `/metrics`; отключить модель (`AI_MODE=no-ai` в подготовленном контуре) и повторить поиск. | Инструменты, ID из БД, резервный ответ и наблюдаемость. Назвать границу: метрика сверки полей карточек не заменяет ручную проверку текста и независимые 10 запросов. |

Не переключать модель и не менять конфигурацию посреди записи: для последней минуты заранее держать отдельный контур с `AI_MODE=no-ai` или показывать уже работающий базовый Compose.
